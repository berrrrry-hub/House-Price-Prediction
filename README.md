#  House Price Prediction

A predictive modeling project to estimate house prices using linear regression and neural networks, completed as part of a class assignment and Kaggle competition.

---

##  Context
This project was part of the *Market Intelligence* course and also submitted to the Kaggle community competition: [Prof. X's Prize – House Price Prediction 2024](https://www.kaggle.com/competitions/prof-xs-prize-house-price-prediction-2024). The dataset contains home sale records from Denver, and the objective is to predict the final sale price of houses.

---

##  Objective
To build and evaluate both a linear regression model and a multilayer perceptron (MLP) to predict house prices, compare their performance, and interpret model behavior using training curves and validation errors.

---

##  Tools & Libraries
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- PyTorch (for building neural networks)
- Google Colab
- Kaggle platform (for evaluation)

---

##  Methodology

1. **Data Loading & EDA**
   - Loaded training/test data
   - Visualized distributions and identified missing values

2. **Preprocessing**
   - Filled missing data
   - Encoded categorical features
   - Normalized numeric features

3. **Modeling**
   - Baseline: Linear Regression using PyTorch
   - Advanced: Multilayer Perceptron (MLP) with hidden layers, dropout, and ReLU

4. **Evaluation**
   - Compared RMSE and validation performance
   - Visualized training/validation loss curves

5. **Prediction**
   - Applied model to test set and submitted results to Kaggle

---

##  Results

- MLP achieved better generalization and lower validation error compared to linear regression
- Submission to Kaggle provided final model performance feedback
- Trained models and plots included in the notebook
